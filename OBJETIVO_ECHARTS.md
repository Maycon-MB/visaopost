# Objetivo: Explorar Exemplos do ECharts

Este repositório tem como um dos objetivos principais **consultar e estudar os exemplos oficiais do ECharts** para:

- Identificar os tipos de gráficos mais adequados aos dados disponíveis.
- Aprender boas práticas de configuração (tooltips, legendas, cores, animações).
- Adaptar padrões de visualização ao nosso tema "premium" (gradientes, glass‑morphism, tipografia Jost).
- Utilizar a documentação e playgrounds online como referência ao implementar novos componentes.

**Próximos passos**
1. Acessar a página de demonstrações: https://echarts.apache.org/examples/pt/index.html
2. Selecionar exemplos de `line`, `area`, `donut` e `heatmap`.
3. Copiar a configuração básica (`option`) e adaptar ao nosso helper de gradiente.
4. Criar componentes React reutilizáveis baseados nesses exemplos.

*Este documento serve como registro de objetivo para a equipe de desenvolvimento.*
